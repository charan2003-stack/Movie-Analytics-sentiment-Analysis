# 🎬 Movie and Sentiment Analytics

## 📌 Overview

This project analyzes movie-related data and predicts sentiment (positive or negative) using Machine Learning and Natural Language Processing (NLP).

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* NLP
* Machine Learning

## 🎯 Objective

To analyze movie data and classify text reviews based on sentiment.

## 🚀 Applications

* Movie review analysis
* Sentiment classification
* Understanding audience opinions
